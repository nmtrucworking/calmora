# Cách đưa bộ tài liệu vào repository

Sao chép thư mục:

```text
senova-blockchain-web-docs/
```

thành:

```text
docs/blockchain-traceability/
```

Commit đề xuất:

```text
docs(traceability): add blockchain and QR unit implementation specifications
```

Không đặt file secret, QR export hoặc khóa blockchain trong thư mục docs.

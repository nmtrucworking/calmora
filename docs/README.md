# Frontend docs — Senova

This folder documents the frontend app located at `apps/frontend`.

Contents:

- `architecture.md` — high-level architecture and important modules
- `development.md` — how to run, build, lint, and preview locally
- `components.md` — shared components and how to use them
- `deployment.md` — Vercel configuration and notes for deployment

This set of docs is intentionally focused on the frontend only; backend docs live elsewhere.
